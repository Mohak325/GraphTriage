# Graph Engine — Network Topology & Fault Gradients

## Purpose
This folder contains the graph engine responsible for maintaining the network topology graph in Neo4j and computing fault gradients for the Navigator Agent.

## Planned Components
- **Topology Builder:** Constructs and maintains the network topology graph from infrastructure data
- **Fault Gradient Calculator:** Computes anomaly propagation scores across graph edges
- **Cypher Query Library:** Optimized Neo4j queries for graph traversal operations
- **Graph Serializer:** Converts Neo4j subgraphs to NetworkX format for algorithmic processing
