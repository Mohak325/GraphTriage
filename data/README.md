# Data — Datasets & Data Generation

## Purpose
This folder contains the datasets used for training, testing, and benchmarking the GRAPHTRIAGE framework, as well as tools for synthetic data generation.

## Structure
```
data/
├── synthetic/     # Custom-generated network topology and fault data
├── benchmarks/    # Public benchmark datasets
└── README.md      # This file
```

## Datasets
- **Synthetic:** Custom Python-based generators for realistic microservice topologies with fault injection
- **AIOps Challenge 2020/2022:** Multi-source anomaly detection data
- **Train-Ticket Benchmark:** Open-source microservice benchmark
- **Sock Shop:** Weaveworks microservices demo
- **Google Cluster Traces:** Large-scale workload traces
