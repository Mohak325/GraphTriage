# Frontend — GRAPHTRIAGE Dashboard

## Purpose
This folder contains the **React / Next.js** frontend application that serves as the real-time monitoring and visualization dashboard for the GRAPHTRIAGE framework.

## Planned Features
- Interactive network topology graph visualization (D3.js / Cytoscape.js)
- Real-time agent activity monitoring (Navigator, Diagnoser, Verifier)
- RCA results display with confidence scores and evidence chains
- Historical incident timeline and audit log
- Dark mode UI with responsive design

## Tech Stack
- **Framework:** React / Next.js
- **Graph Visualization:** D3.js or Cytoscape.js
- **State Management:** Zustand / Redux Toolkit
- **Styling:** Tailwind CSS / CSS Modules
- **API Client:** Axios / Fetch
