# Results — Evaluation & Benchmarking

## Purpose
This folder will contain evaluation results, benchmark comparisons, performance metrics, and analysis visualizations produced during the testing phase of the GRAPHTRIAGE framework.

## Planned Contents
- Accuracy comparison tables (GRAPHTRIAGE vs. baselines)
- Latency and throughput benchmarks
- Hallucination rate measurements
- Ablation study results (individual agent contributions)
- Visualization plots and charts
- Statistical significance tests

## Evaluation Metrics (Planned)
| Metric | Description |
|--------|-------------|
| **Top-K Accuracy** | Percentage of incidents where the true root cause is in the top-K predictions |
| **Mean Time to Diagnose (MTTD)** | Average time from incident detection to diagnosis |
| **Hallucination Rate** | Percentage of diagnoses that are structurally or semantically incorrect |
| **Precision / Recall / F1** | Standard classification metrics for root cause identification |
| **Agent Utilization** | Average number of agent iterations before convergence |
